FIFASTATX is an interactive, scenario-based football analytics web application designed to simulate and evaluate isolated 1-versus-1 player matchups using situational statistical attributes. Moving away from traditional, opaque "black-box" machine learning predictions, this system delivers transparent and explainable sports insights.

Key Features
Scenario-Aware Simulation: Evaluates 1v1 matchups across diverse game-states (e.g., dribble duels, aerial battles, pace breakaways) by dynamically adjusting attribute importance.  
Realism-Enhanced Scoring Engine: Combines mathematical interaction functions, pressure modeling, and probabilistic sigmoid scaling to calculate outcomes.  
User-Controlled Uncertainty: Features an adjustable randomness slider that simulates the natural, unpredictable nature of real-world football matches.  
Explainable Visualization Layers: Outputs bounded success probabilities (ranging from 5% to 95%) alongside comparative side-by-side bar charts and multi-attribute radar plots.

Technical Architecture & StackCore Analytics Engine: Developed in Python, utilizing Pandas and NumPy for data filtering, matrix computations, and normalized attribute interaction logic.  
User Interface: Built with Streamlit, providing a responsive and interactive dashboard framework for real-time player comparisons and probability visualizations.  
Data Visualization: Implemented using Matplotlib to render real-time impact charts and Circular Radar Plots.
